Closed-loop speed PID

Trims the pot's feedforward ERPM command using the VESC's own measured ERPM (fed back over CAN) — helps hold a steady speed against slope/load instead of just commanding a fixed ERPM per pot position. Off by default; the existing open-loop mapping already drives the motor without this. Only applies in Speed (RPM) control mode (System tab) — ignored entirely while Current mode is selected, since there's no RPM setpoint to trim against.

Fall detection

The buzzer always sounds before motor control resumes after a safety interruption.

On a fall: motor output is cut immediately (CAN commands stop). Once the device is back upright and stays that way for the "auto-recover stable time" above, it does not resume immediately — the motor stays off until the pot is back in its centered dead zone too (so it can't lurch off in whatever direction the pot got knocked to during the fall), then the buzzer beeps a few times as a "starting now" warning, and only after that finishes does normal control resume. No button press needed for any of this, but you can also force-clear the fall latch below.

Control mode

What the pot commands the VESC to do. Takes effect immediately, no restart needed.

Use this if Forward drives the physical motor backward. For safety, a changed direction stays locked at zero until the handle is centered.

Pick the unit above; the other one becomes a grayed-out, live-computed equivalent (using the pole pairs / wheel diameter / gear ratio in "Speed / distance conversion" below) so you can sanity-check either number. Get pole pairs/wheel/gear right first, or the km/h number will be off by whatever those are wrong by — same as the speed telemetry.

The Speed PID tab's closed-loop trim only applies in Speed (RPM) mode — it's ignored while Current mode is selected.

Reverse / backward limits

Separate limits for the backward direction. Turning reverse off forces exactly zero torque that way — not just a lower limit — enforced as a final clamp on whatever gets sent over CAN, so a PID trim or anything else can't override it.

Uses the same speed limit unit selected above.

Downhill braking & Park

When the wheel is spinning faster than the pot currently asks for — e.g. rolling downhill under its own weight — send an active braking command instead of just easing off. Off by default; without this the motor simply freewheels/coasts when overspeeding. Not affected by the reverse toggle above: braking resists whatever direction it's already moving, it never drives it.

Park uses the VESC handbrake controller to hold the wheel's current position. Use the lowest holding current that works reliably; continuous holding current heats the motor and VESC.
